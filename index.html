agent-graph-tui

Single-binary terminal dashboard for AI coding agent sessions. Surfaces every active Claude Code / Codex / MiniMax / Gemini session on the machine, grouped by repo → branch, with live/idle status — and drills into any session's full execution graph. Read-only, no daemon, ~0.7MB binary, ~1s cold start, ~10MB RSS.
